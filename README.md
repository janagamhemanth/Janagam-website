# Hemanth Jangam — Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, and styling
- `script.js` — mobile navigation and small interactions

## Before publishing
Open `index.html` and update these placeholders:
1. Replace `your.email@example.com` with your professional email address.
2. Replace the GitHub profile link `https://github.com/` with your GitHub profile URL.
3. Replace the two `href="#"` project links in the Warrantiq section with your deployed project URL and GitHub repository URL.
4. Check your LinkedIn URL and education/certification details for accuracy.
5. If you want to show a profile photo, add your own image and update the HTML. The current design uses a code-card illustration instead.

## Preview on your laptop
You can open `index.html` directly in a browser. For a better development workflow, open the folder in VS Code and use the Live Server extension.

## Deploy free with GitHub Pages
1. Create a GitHub repository, for example `hemanth-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will be shown in the Pages section.

## Deploy free with Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Import an existing project** and connect your GitHub repository, or drag and drop this project folder into Netlify's manual deploy area.
3. No build command is needed. Set the publish directory to the project root if prompted.
4. Open the generated site URL after deployment.

## Notes
- This is a static website; it does not need Node.js, MongoDB, or environment variables.
- The site is responsive for mobile, tablet, and desktop.
- Do not publish private information such as home address, personal ID numbers, or passwords.
